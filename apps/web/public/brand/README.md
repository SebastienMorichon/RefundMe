# Logo Lydoc

Le symbole « Chemin clair » associe un document plié, l'initiale L et un chemin de validation.

- `lydoc-logo.svg` : logo horizontal pour les supports courants.
- `lydoc-mark.svg` : icône sur fond menthe, utilisée comme favicon.
- `lydoc-mark-flat.svg` : symbole sans fond.
- `lydoc-mark-mono.svg` : version monochrome sombre.
- `lydoc-mark-inverse.svg` : version blanche pour fond sombre.

Couleurs : vert `#087A55`, encre `#17211D`, menthe `#E8F7F0`, pli `#BFE5D3`.
Conserver autour du symbole une marge libre au moins égale à un quart de sa largeur.
